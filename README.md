# Student Task Manager

## Project Description

Student Task Manager is a simple web-based application designed to help students manage their tasks. Users can add tasks by entering a task title and description, and they can search tasks using the search feature. The project was developed collaboratively using Git and GitHub.

## Features

- Add a new task
- Enter task title and description
- Display added tasks
- Search tasks by title
- Search tasks by description
- Responsive and user-friendly interface
- Task manager styling
- GitHub-based collaborative development

## Git Workflow

The project followed a collaborative Git workflow:

1. The project was initialized using Git.
2. An initial commit was created.
3. The project was connected to a GitHub repository.
4. Feature branches were created for different tasks.
5. Changes were committed using meaningful commit messages.
6. Feature branches were pushed to GitHub.
7. Pull Requests were created for merging features.
8. Pull Requests were reviewed before merging.
9. Merge conflicts were intentionally created and resolved.
10. Git recovery commands such as stash, restore, reset, and revert were demonstrated.
11. A final version tag `v1.0.0` was created.
12. A GitHub Release was created for version `v1.0.0`.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/rimshabhatti2025/student-task-manager
```
2. Open the project folder:

```bash
cd student-task-manager
```

3. Open `index.html` in a web browser.

The Student Task Manager application will then be displayed in the browser.
